# Sakura Nyan · 二次元界面素材说明

本目录存放 Selandia Niri「樱花喵 Sakura Nyan」主题族使用的看板娘「Nyx 酱」透明立绘与手写矢量贴纸/符号图标。所有 SVG 均为单文件、无外部引用，配色与 `niri/shell/appearance.py` 的 `sakura` 令牌保持一致；带 `-symbolic.svg` 后缀的版本以 `#000000` 填充，供 GTK 图标引擎按主题前景色动态重着色。

## 看板娘「Nyx 酱」立绘（PNG，透明底）

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `mascot-full.png` | 301×512 | 控制中心左侧导航栏底部立绘（`.nav-mascot`） |
| `mascot-peek.png` | 331×320 | 控制中心顶部横幅右下探头立绘（`.control-header`） |
| `mascot-avatar.png` | 256×256 | 控制中心头部圆角头像与日历抽屉点缀 |
| `mascot-avatar-64.png` | 64×64 | Eww 顶栏左侧启动器胶囊头像（`.launcher-btn`） |
| `mascot-sleepy.png` | 347×380 | 电源菜单顶部/底部困倦猫娘点缀与锁屏合成源图 |
| `mascot-thinking.png` | 295×420 | AI 抽屉顶部横幅托腮思考立绘（`.ai-window`） |
| `lock-bg.png` | 1920×1080 | Swaylock 樱花夜空锁屏背景（Nyx 酱置于下方避让密码圆环） |
