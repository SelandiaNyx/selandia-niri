# 控制中心视觉回归维护

状态圆角在基础与选中／勾选／按下规则中均显式声明。导航、壁纸行／网格、快捷磁贴、页签、详情按钮及数字输入保持各自半径。图形测试必须先加载基础、控制中心和生成样式；只构造 `Panel` 不会调用 `Shell.do_activate()`，未加载样式的原生主题截图不能代表实际应用。

控制中心改为普通浮动窗口，授权、文件选择和其他应用对话框可以盖过它；日历／AI 侧栏仍保留原图层。更新后保存草稿再关闭重开控制中心，不必重启桌面。

灵动岛通知预览遵循 SwayNC 的勿扰、抑制和通知中心可见状态。紧急通知或明确设置 `SWAYNC_BYPASS_DND` 的通知可绕过勿扰／抑制，通知中心打开时仍收起预览。关闭或清空通知会同步收起对应预览；结束勿扰不会重放期间的通知。预览按请求时长或 SwayNC 默认时长展示，最多 8 秒；常驻通知仍保留在通知中心。通知服务退出时撤下预览，恢复后自动重新同步。

顶栏现由 Eww 的三个有界图层提供，生成器负责胶囊材质；时间仅在右侧，点击打开独立日历。所有表面使用同一不透明度，20%–100% 可调。删除了旧 Waybar 样式生成分支，原生 Eww 验证使用 `--bar-island-probe-only`。

音量与亮度快捷键优先显示灵动岛，顶栏不可用时改用通知。音量显示当前百分比或“已静音”，右侧音量图标同步静音状态；从其它混音器切换静音也会更新。麦克风静音保留独立的“麦克风”通知，不与扬声器音量混淆。

不透明度低于 40% 时，面板图层去除噪点，文字使用无模糊半径的 1px 四向描边与完整前景色。保持用户的表面 alpha，不增加下限，也不改变面板动画；动画结束后的窗口／表面 widget opacity 必须为 1。描边像素和壁纸模糊分别验收，不能用一张截图的主观观感代替字形边缘验证。

壁纸页顶部保留当前缩略图、标题、类型／模式与刷新，其余内容同页滚动可达，不再有“资源库／播放集／播放设置”子页切换。宽屏为左资源库、右设置区（含播放集）的左右分栏，中间分隔可拖动；窄屏上下排列。宽窄屏都保留同一份选择、搜索和播放集草稿。设置区靠前展示所选预览、显示方式与分级筛选下拉，文件／目录／资源与音量、播放集在下方。资源库保持单层滚动，不进子页就不会应用或丢弃草稿。播放集自动调度继续由壁纸服务执行。窄屏缩短导航并隐藏重复的壁纸页标题，腾出两行列表的实际空间。

## 复现与量化验收

在项目临时副本中运行，使用独立 D-Bus；测试仅操作自己创建的嵌套 Niri 窗口：

```bash
dbus-run-session -- python3 -B tools/smoke.py --visual-defects-probe-only
dbus-run-session -- python3 -B tools/smoke.py --panel-probe-only
dbus-run-session -- python3 -B tools/smoke.py --popup-probe-only
./check.sh
```

`tools/visual_defects_probe.py` 把 JSON、GTK 像素图与原生 Waybar／高细节壁纸截图保存到 `.validation/visual-defects-20261010/after/`：

- 用同一 GTK 场景中目标 widget 透明时的背景作为参照，断言选中状态四角保持背景色；不能硬编码主题的背景 RGB。
- 所有 13 个胶囊 ID 及控制中心／AI 悬停、工作区强调状态，在 20% 与 100% 下逐项检查内部背景像素有变化。
- 固定高对比棋盘壁纸，对比无顶栏和有顶栏的原生截图。胶囊空隙须逐像素保持原背景，不存在整条横向色带。
- 将同一段 GTK 字形的无阴影渲染当作参考，统计超出字形与 1px 描边范围的软阴影像素，同时要求不透明字形核心保持逐像素一致；原生面板再分别截图 20／25／30% 并检查动画最终 opacity。
- 测量宽屏与 600 逻辑像素窄屏的真实分配、祖先裁剪交集与完整可见列表行数（至少 2）。滚动区的 `min_content_height` 或 `page_size` 不能替代实际可见范围。

历史版本 A/B 复现额外使用本次证据目录中的原始源码／生成样式快照；正常验收不需要这些快照。正式更新使用 `tools/live_update.py` 的持久回滚记录和 systemd 托管组件，禁止重启 Niri 合成器。

## 壁纸精细控制

页面设置区内的“播放集”可管理多个名称、编辑排序/权重/启用，明确保存后生效；支持秒/分钟定时、顺序/随机/洗牌。同一设置区可调六种显示模式、静态淡入淡出时长，以及全部、Everyone、PG13、Mature、未分级的单选分级筛选；分级自动读取作者元数据，UI 不再提供手动分级编辑，启用 Mature 需确认。宽窄屏保持资源库单层滚动，窄屏时资源库与设置区纵向排列。完整字段、后端限制与迁移说明见 [壁纸播放集指南](WALLPAPERS.md)。

独立日历与控制中心共享字体、颜色、不透明度、减少动态效果设置；时间/时区修改仍通过控制中心时间页完成。

日历月份和星期随应用中英文选择切换，周一为首列并显示 ISO 周数。方向键选择相邻日期，Page Up/Down 换月，Ctrl+Page Up/Down 换年；“今天”返回当日，“复制日期”复制所选 `YYYY-MM-DD`。

## 紧凑顶栏与当前软件

左侧最后一个胶囊显示当前焦点软件，软件名来自本机 desktop entry，窗口标题以普通文本作为悬停提示。焦点与工作区由 Niri 事件流更新，同一窗口频繁变化的标题合并刷新。没有焦点窗口显示“桌面”，IPC 不可用显示“不可用”，重连后重新接收快照。

两侧胶囊不再拉伸到字体放大后的窗口高度。收起高度按相同字体的 Pango 字形高度与岛内边距计算，下限 44px；以字体 16px 为测试样例保留 44px 历史配置。横向内边距不变，仅新增的软件名胶囊占用左侧剩余空间，长名称截断；选中、悬停和按下也保持椭圆。Rust 输入区域同步轮廓，圆角和胶囊间隙仍可穿透鼠标；岛展开不改变左右胶囊几何。

原生探针 `tools/smoke.py --bar-island-probe-only` 覆盖 800/1600 宽度、12/16/20px 字体、20%/100% 不透明度，逐胶囊比较高度、背景 alpha 与穿透点击，并切换两个真实 GTK 软件窗口验证焦点软件名与可见文本像素变化。新证据目录见项目 VALIDATION.md。
